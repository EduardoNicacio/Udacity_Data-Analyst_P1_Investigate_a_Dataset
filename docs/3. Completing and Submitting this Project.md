# Completing and Submitting this Project

You have two options for working on and submitting your project:

## Option #1

On the **Project Workspace** page, you find a Jupyter Notebook environment for the project. This is great if you do not want to work on your local machine or worry about system requirements. The environment will continually save your work.

### Submission

If you choose option #1, submit your project directly from the workspace. There are directions at the end of the Jupyter Notebook there in the workspace for adding your HTML or PDF file to the workspace before you submit it.

### Reset data or refresh the workspace

You can upload, download or delete files as you feel necessary. In case something goes wrong, you can either reset your data or refresh the entire workspace to its original state by clicking on the **Menu** option on the bottom-left of your workspace. See the snapshot below.

**WARNING**: resetting the data will erase all of your work. Make sure you have downloaded a copy of any files you want to save before resetting!

![Menu options at the bottom left of the workspace](https://video.udacity-data.com/topher/2023/February/63e95135_screen-shot-2023-02-12-at-12.49.26-pm/screen-shot-2023-02-12-at-12.49.26-pm.jpeg)

### Upload, Download, or Delete files

From the Jupyter notebook, click on the Jupyter icon on the top-left to navigate to the Jupyter server, where you can either upload, download, or delete individual files.

![Files present in the Jupyter server](https://video.udacity-data.com/topher/2023/February/63e9600a_screen-shot-2023-02-12-at-1.48.22-pm/screen-shot-2023-02-12-at-1.48.22-pm.jpeg)
<center>Files present in the Jupyter server</center>

**Pro Tip**: You cannot download a folder from a Jupyter server in one go. Instead, you must download individual files.

## Option #2

You can work on your Jupyter Notebook on your local machine. To do this, you would need the following files:

1. Investigate_a_Dataset.ipynb starter file. Download this file from the project workspace (Jupyter server).
2. Either one of the following dataset databases.

- Database_Ncis_and_Census_data
- Database_No_show_appointments
- Database_TMDb_movie_data

You can download the dataset files from one of the database directories from the project workspace (Jupyter server).

### Submission

If you choose option #2, zip your project files locally and submit them using the **"Project Submission"** page.

⚠️ **Choose either one of these two options above - don't try to submit your project in both places.**
